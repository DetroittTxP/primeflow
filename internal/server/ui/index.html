Settings

GitOps target repository

The repository worker specs are rendered and committed into. The token is stored write-only and never returned. Sync commits straight to the branch below — no pull request — so point it at a repo where that is expected (a GitOps config repo). Secret values in the rendered manifests are placeholders; replace them with a SealedSecret / SOPS entry in the repo. Turn on Auto-sync per spec to have the reconciler push drift automatically.

Access

The master switch for every key at once. With this off, all /api/external/v1/* requests are refused before any key is checked. Every endpoint accepts its key via Authorization: Bearer <key> or X-API-Key: <key>. A key whose role lacks the endpoint's scope gets a 403 rather than a 401.

Log retention

The janitor deletes older run logs every 30 min. Task state, artifacts and events are untouched.
